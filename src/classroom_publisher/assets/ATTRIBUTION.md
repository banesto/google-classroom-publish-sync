# Icon sources

`google-classroom.png` is Google's unmodified square Classroom integration icon from:
https://developers.google.com/static/workspace/classroom/assets/classroom_square_logo.zip
(96x96_yellow_stroke_icon@2x.png). `google-classroom.ico` contains proportionally resized versions for Windows Explorer.

Google Classroom is a trademark of Google Inc. Use of this trademark is subject to Google Brand Permissions. The icon identifies the Classroom destination of the publishing menu action; it is not the logo of this independent application. Branding guidance: https://developers.google.com/workspace/classroom/brand

The three `chalkboard-*` designs are original artwork created for this project, not modified Google trademarks. `scripts/build-icons.py` reproduces them. They identify the Classroom Publisher application and can be selected for its desktop shortcut.
