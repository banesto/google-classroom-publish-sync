# Project rules
Never upload or copy attachments. Use existing child-owned Drive items only.
Never automatically retry Post. Preserve pending attempts after any ambiguous outcome.
classroom-published.txt is the only success marker. No database.
Validate the whole folder before launching a browser; more than 20 files blocks all publication.
Do not claim live feasibility, attachment ordering, or automatic verification without observed evidence.
Keep credentials and persistent profiles out of source control and synced folders.
Run python -m unittest discover -s tests with PYTHONPATH=src after changes.
